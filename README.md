# Data-Analytics-ETL-Project
Extracting using Kaggle API, transforming using python, loading into MSSQL and doing analysis in SQL

This project demonstrates the end-to-end process of working with a Kaggle dataset, starting from dataset retrieval to answering interesting questions using SQL. The workflow integrates Python for data processing and Microsoft SQL Server for data storage and querying.

Steps Involved:
Dataset Retrieval:

Use the Kaggle API to download the dataset directly from Kaggle. This ensures the process is automated and reproducible.
Data Processing and Cleaning:

Perform data wrangling and preprocessing using Python's pandas library. This step involves handling missing values, standardizing formats, and preparing the dataset for loading into the database.
Loading Data into MS SQL Server:

After cleaning the dataset, it is loaded into a Microsoft SQL Server database. This allows efficient storage and querying of the data.

Answering Some Interesting Questions:

Leverage SQL queries to derive meaningful insights from the dataset. These queries explore key patterns, trends, and relationships within the data.

Technologies Used:
Python: For data processing and integration with the Kaggle API.
Pandas: For data cleaning and manipulation.
Kaggle API: For dataset retrieval.
Microsoft SQL Server: For data storage and querying.
SQL: For analytical queries and insights.
